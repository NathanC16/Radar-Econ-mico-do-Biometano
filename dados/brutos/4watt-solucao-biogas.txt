Perguntas frequentes
O que mais perguntam.
Quanto tempo leva um projeto básico?
De 8 a 14 semanas a partir da assinatura. Projetos mais complexos podem levar até 18 semanas.
A 4WaTT faz projetos para todos os tipos de resíduo?
Sim. Temos experiência com bovinos, suínos, avícolas, frigoríficos, vinhaça de cana, RSU, lodo de ETE e resíduos industriais.
O que está incluído no estudo de viabilidade?
Levantamento e análise do substrato, dimensionamento de geração, análise de uso energético, CAPEX/OPEX, modelo financeiro com TIR/VPL/payback, análise de sensibilidade e recomendação de tecnologia, formatado para apresentação a financiadores.
Vocês trabalham com licenciamento ambiental?
Em parceria com escritórios especializados. O projeto básico já é concebido com os requisitos ambientais em mente, com suporte de RAP, dados de emissões e fluxos de massa.
Qual a diferença entre projeto básico e executivo?
O básico define o que será construído e como (tecnologias, equipamentos, layout, especificações, custo). O executivo detalha como construir (memoriais de cálculo, detalhamentos, documentos para execução sem ambiguidades). O BNDES geralmente exige o executivo completo.
A simulação gratuita já não me dá a viabilidade?
A simulação entrega uma estimativa de mercado em poucos minutos — é útil para descartar projetos inviáveis. Mas o número que um banco aceita para liberar crédito exige levantamento de substrato, modelagem financeira com TIR/VPL/payback, ART e documentação técnica. É isso que o Projeto de Investimento 4WaTT entrega.
Como é pago o Projeto de Investimento?
A entrada do projeto pode ser parcelada ao longo da elaboração, alinhada aos marcos de entrega (viabilidade, projeto básico e modelagem financeira). A obra propriamente dita é financiada com terceiros; o cliente precisa ter caixa para a entrada, não para a construção completa.
